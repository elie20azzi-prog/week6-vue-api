# Week 6 Build Log - Vue.js Fundamentals

## Goal

Build a small Vue.js application that consumes a public API and demonstrates the main Vue fundamentals covered during Week 6.

## What I Built

I created a Vue application called **Vue User Explorer**.

The application fetches users from the JSONPlaceholder public API and displays them in reusable Vue components.

The user can navigate between pages, view users, and select a user to display more details.

## Concepts Practiced

### Components

Created a reusable `UserCard.vue` component to display user information.

### Props

Passed each user object from `UsersView.vue` to `UserCard.vue` using props.

Example:

```vue
<UserCard :user="user" />
Events

The UserCard component emits a custom select event when the View User button is clicked.

The parent UsersView.vue listens for the event and stores the selected user.

Composition API

Used Vue's Composition API with:

ref
onMounted
<script setup>

ref was used for reactive state, and onMounted was used to fetch users when the page loads.

Routing

Used Vue Router to create two routes:

/ - Home page
/users - Users page

Navigation is handled using RouterLink and page content is displayed using RouterView.

State Management

Used Pinia for state management.

Created:

src/stores/users.js

The store manages:

users
loading state
error state
API fetching
Public API

Used the JSONPlaceholder users API:

https://jsonplaceholder.typicode.com/users

The application fetches user data using JavaScript fetch().
